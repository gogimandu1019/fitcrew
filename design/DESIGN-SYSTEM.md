# FitCrew 디자인 시스템 v0.1

출처: 디자인 컨셉 제안(시안 7장)에서 값을 직접 추출 + 개발 계획에서 새로 정한 항목 보강.
파일: [app/src/design/tokens.ts](../app/src/design/tokens.ts) (앱에서 import) · [design-system.html](design-system.html) (눈으로 확인)

## 컨셉: 불 켜진 크루

오늘 운동한 사람의 불이 켜진다. 내 불만 꺼져 있으면 괜히 신경 쓰인다. 이 "가벼운 신경 쓰임"이 화면의 중심이다.

| 원칙 | 화면에 적용하는 방법 |
|---|---|
| 라임은 "했다"의 신호 | 완료 링, 주간 카드, 1위 단, 기록 버튼, 진행 막대에만 쓴다. 나머지는 어둡게 눌러 라임이 먼저 보이게 한다 |
| 시간이 공통 언어 | 종목이 달라도 비교 단위는 시간. `2:25` 같은 숫자를 컨덴스드 굵은 서체로 가장 크게 |
| 압박은 가볍게, 소속은 분명하게 | 순위보다 "오늘 누가 켰나"를 먼저. 꺼진 사람은 지워지지 않고 어두워질 뿐. 미활동·강퇴는 크루장에게만 |

## 시안에서 추출한 값

- **색:** Lime `#C8F031` · Night `#0E0F0E` · Card `#181A18`(테두리 `#2B2E2B`) · Off `#2A2D2A` · Field `#222522` · 글자 `#F2F4EF`/`#C9CEC4`/`#9AA096`/`#8A9086`/`#6C726A`
- **서체:** 숫자 Barlow Condensed 600/700/800, 한글은 시스템 폰트(시안은 Noto Sans KR이었으나 변경, 아래 결정 참고)
- **반경:** 입력칸 12 · 버튼 16 · 카드 20 · 히어로 카드 28 · 칩 pill
- **크기:** CTA 높이 56, 입력칸 54, 화면 좌우 여백 20, 아바타 38/40/48

## 이번에 새로 정한 것 (시안에 없던 것)

1. **종목 팔레트 8색:** 하늘, 코랄, 보라, 앰버(시안 값) + 민트, 핑크, 오렌지, 화이트(추가). 라임은 제외. 사용자가 종목마다 색을 고른다. 칩 배경은 색 + 14% 투명도.
2. **기본 추천 종목 5개:** 러닝(민트), 수영(하늘), 헬스(코랄), 요가(보라), 사이클(앰버). 기록 화면에서 칩으로 보이고, 직접 입력으로 다른 종목을 쓸 수 있다.
3. **아바타 팔레트 8색:** 멤버별 고정 배정. 라임은 완료 링 전용이라 제외.
4. **오류색** `#FF5C5C`: 코랄(헬스)과 구분하려고 아이콘·문구와 항상 같이 쓴다.
5. **새 컴포넌트:** 진행 표시줄(1/3~3/3), 세그먼트 컨트롤, 텍스트 입력(기본/포커스/오류), 코드 입력칸 오류 상태, 종목 입력+색 선택, 하단 탭, 오류 토스트, 빈 상태, 위험 동작 버튼.
6. **하단 탭 3개 + 띄운 기록 버튼.** 탭은 홈 · 랭킹 · 내 정보. 기록 추가는 탭이 아니라 '내 정보' 탭 바로 위에 12px 띄운 라임 버튼(64×56, 시안의 기록 버튼 모양 그대로)이고 모든 탭 화면에서 같은 자리에 있다. 스크롤 목록은 버튼에 가리지 않게 아래 여백을 168px 둔다. 시안의 홈·랭킹·그룹 전환 시트는 4탭이라 3탭으로 다시 그려야 한다.
7. **모션 3개만:** 기록 저장 후 내 링이 켜지는 280ms, 진행 막대 400ms, 탭 눌림 스케일 0.97. "불이 켜지는 순간"에만 움직임을 쓴다.

## 대비 검사 결과 (배경 `#0E0F0E` 기준)

- 종목 팔레트 8색 전부 7.5:1 이상 (가장 낮은 건 코랄 7.5, 화이트는 약 19:1)
- 글자: 기본 17.3 · sub 12.0 · muted 7.2 · disabled 5.9 · **dim 3.9**
- 비활성 버튼 글자(`#8A9086` on `#222522`) 4.7:1

## 결정 기록

1. **라임은 종목 색에서 제외, 화이트 추가.** 라임은 "했다" 신호 전용(완료 링, 주간 카드, 1위, 기록 버튼). 새 색 후보를 기존 7색과 색 차이(ΔE)로 비교했다. 화이트 42(가장 가까운 민트 기준), 인디고 16(보라와 혼동), 틸 20(민트와 혼동), 레몬 23(앰버와 혼동). 화이트가 가장 확실히 구분된다. 본문 글자색 `#F2F4EF`와 같은 값이 되지 않도록 종목 색은 순백 `#FFFFFF`로 정했다. 러닝 기본색은 민트로 바꿨다.
2. **한글은 시스템 폰트.** 앱 용량이 늘지 않고 OS 기본 글자와 맞는다. 코드에서는 `fontFamily`를 지정하지 않는다. 시스템 폰트는 900 굵기를 안정적으로 지원하지 않아 제목은 800으로 낮췄다(시안은 900). 숫자(시간, 순위, 코드)만 Barlow Condensed를 앱에 포함한다. 이 서체는 "숫자가 주인공"이라는 시안의 핵심이다.

3. **꺼진 아바타 글자 상향.** 시안의 `#6C726A` on `#2A2D2A`는 2.8:1로 약해서 `#8A9086`(4.3:1)으로 올렸다. 토큰 `avatarOffText`.
